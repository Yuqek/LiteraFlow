# Безопасность

## API-ключи

Никогда не добавляйте ключи и keystore в репозиторий. LiteraFlow пытается использовать системное хранилище секретов; без него ключ хранится только в текущем сеансе, если пользователь явно не выбрал запоминание.

Для GitHub Actions передавайте секреты только через **Settings → Secrets and variables → Actions**. Android keystore должен храниться в секрете в base64-виде и восстанавливаться лишь на время release-сборки.

## Отчёт об уязвимости

Не публикуйте рабочий ключ, приватный текст книги или базу проекта в Issue. В отчёте оставьте минимальный воспроизводимый пример с обезличенными данными.

## Сетевые сервисы

Google, LanguageTool, Ollama и пользовательские API являются внешними или отдельно запущенными сервисами. Перед отправкой конфиденциального текста проверьте их политику хранения данных. По умолчанию LiteraFlow не запускает AI автоматически.
