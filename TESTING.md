# Проверка релиза

## Автоматически

```bash
python -m pip install -r requirements.txt
python -m unittest -v test_literaflow_core.py
python -m py_compile main.py test_literaflow_core.py
```

## Вручную на ПК

- Открыть каждый входной формат.
- Изменить сегмент, закрыть приложение и проверить восстановление.
- Проверить Ctrl+Enter, Alt+↑/↓, Ctrl+S, Ctrl+Z/Y.
- Открыть книгу на 15 000+ сегментов и выполнить дальние переходы.
- Проверить все варианты экспорта и открыть результаты целевыми приложениями.

## Вручную на Android

- Открыть файл через системное окно выбора.
- Проверить вкладки при открытой клавиатуре и повороте экрана.
- Проверить постоянную панель «Назад / Готово / Далее».
- Оставить приложение в фоне, вернуть его и проверить сохранение.
- Проверить DOCX/EPUB на файлах из доступного Android-хранилища.

## EPUB/DOCX

- Запустить `epubcheck` для экспортированного EPUB.
- Сравнить обложку, оглавление, иллюстрации и CSS с исходником.
- Открыть DOCX в Microsoft Word и LibreOffice.
- Проверить TL-сноски и сложные inline-блоки в каждом выбранном режиме политики.

## Перед публичным релизом

- Выполнить release-сборку с приватным keystore.
- Проверить обновление поверх предыдущей версии.
- Прогнать smoke-test минимум на одном ARM64-телефоне и одном планшете.
