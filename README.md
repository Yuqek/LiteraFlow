# LiteraFlow

> Переводи историю, а не строки.

LiteraFlow — локальная CAT-среда для перевода художественной прозы, веб-новелл и ранобэ. Приложение объединяет сегментный редактор, живую вычитку книги, память переводов, глоссарий, QA и бережный экспорт DOCX/EPUB в одном интерфейсе.

## Что уже работает

- адаптивный интерфейс: три колонки на ПК и четыре понятные вкладки на телефоне;
- стартовый экран с продолжением последней книги и недавними проектами;
- сегментация, статусы, закладки, варианты перевода и TL-сноски;
- локальная SQLite-база и переносимая `.progress.json`-копия;
- карта глав с прогрессом, пустыми сегментами, закладками и QA;
- режим чтения для финальной вычитки абзацами;
- мастер проверки перед экспортом;
- TXT, Markdown, DOCX, EPUB, FB2 и XLIFF на входе;
- TXT, DOCX, EPUB, FB2 и XLIFF на выходе;
- сохранение структуры, иллюстраций и стилей совместимых DOCX/EPUB;
- офлайн-морфология и словарь проекта;
- необязательный помощник: Google без ключа, собственный OpenAI-совместимый API или скрытая Ollama.

AI в LiteraFlow не запускается сам: ручной перевод остаётся главным сценарием, а автозаполнение включается отдельно.

## Быстрый запуск

Требуется Python 3.10–3.12.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```

Дополнительные функции безопасного хранения ключей и TTS:

```bash
python -m pip install -r requirements-desktop.txt
```

## Проверка

```bash
python -m unittest -v test_literaflow_core.py
python -m py_compile main.py test_literaflow_core.py
```

Набор тестов проверяет SQLite-сессии, защиту от запоздалого AI-ответа, типографику, TL-сноски, DOCX/EPUB, сводки UX и сегментацию 20 000 предложений.

## Android APK

Откройте вкладку **Actions** в GitHub и запустите workflow **Build Android APK**. Готовый APK появится в артефактах запуска. Workflow собирает тестовый APK с debug-подписью; для Google Play нужен собственный keystore и AAB.

Локальная команда:

```bash
python -m pip install "flet[all]==0.28.3"
flet build apk . --verbose
```

Для сборки требуются JDK 17 и Android SDK; Flet умеет подготовить отсутствующие компоненты при первом запуске. Бинарные Python-зависимости должны иметь Android wheels, поэтому desktop-дополнения намеренно отделены от основного `requirements.txt`.

## Данные и приватность

- Книги, переводы, глоссарии и история хранятся на устройстве.
- Google и пользовательские API получают текст только при ручном вызове перевода или включённом пользователем автопилоте.
- Не добавляйте API-ключи, `literaflow.db`, конфигурацию и экспортированные книги в Git.
- Публичный endpoint Google без ключа может ограничивать частоту запросов. Для стабильной пакетной работы используйте собственный API-профиль.


## Ограничения текущей версии

- Сложная inline-разметка DOCX/EPUB не меняется молча: приложение просит упростить блок или оставить оригинал.
- Физические Android-устройства и `epubcheck` нужно проверять перед публичным релизом.
- Публикация в Google Play и release-подпись не настроены, потому что ключ подписи должен принадлежать владельцу приложения.
